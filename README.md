# Amazon Product Review Analysis

## Project Overview
This project analyzes Amazon product review data using Python, MySQL, and Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL
- Power BI

## Project Steps
1. Data Cleaning
2. Data Visualization
3. Python to MySQL Connection
4. SQL Analysis
5. Power BI Dashboard

## Key Insights
- Most products received ratings between 4 and 5.
- Positive reviews were higher than negative reviews.
- Some categories showed better customer satisfaction.
